After — one interface per producer shape

Snapshot builder (deep)

fromStatusline(json, prev, at)

RateLimitWindow · UsageParsing · field-ownership merge · dict digging — all internal

Problem.
One concept — vendor JSON in, Snapshot out — is sliced into three shallow modules; both producers re-compose the slices by hand, in untestable main.swift files. Snapshot merge's 9-argument interface is nearly as complex as its implementation.
Solution.
One deep Kit entry point per producer shape, taking raw JSON plus the previous Snapshot; it absorbs the parsing, the per-source shape, the field-ownership rule, and the dict digging now inlined in both executables.

Wins

  • Leverage: one interface, two producers
  • Interface shrinks: 9 args → 3
  • Whole JSON→Snapshot path becomes testable
  • Deletes duplicated compose dance in both mains

Deletion test: delete RateLimitWindow or Snapshot merge today and their complexity reappears in both producers — they earn their keep, but at the wrong altitude. The new module concentrates it once.

Problem.
The Poller interleaves keychain I/O, network I/O, the 401→"token expired" hint policy, and the backoff schedule in top-level script code — real behaviour with no locality and no tests.
Solution.
A Usage poller module in TokengochiKit with an injectable fetch adapter; backoff and status-hint policy become pure implementation behind a small interface, and main.swift shrinks to wiring.

Wins

  • Locality: retry bugs concentrate in one module
  • Backoff schedule finally unit-tested
  • Interface is the test surface
  • Same seam shape as Snapshot store

Solution.

Problem.
UsageStore fails the deletion test's inverse: it is a shallow pass-through whose body is mostly re-unpacking the Snapshot that Pet session just returned — epoch→Date conversion and reset/freshness text live in an untestable view-model.
Solution.
Pet session (or a small projection alongside it) returns display-ready state; UsageStore keeps only the timer and the @Published plumbing.

Wins

  • Projection joins the tested interface
  • Delete the pass-through unpacking
  • Locality: one place decides display fields

5 · Make AppPaths injectable; surface the hidden migration

Worth exploring local-substitutable

Sources/TokengochiKit/AppPaths.swift:28–35 · UsageSnapshot.swift · PetState.swift

Before — a path getter that moves files

AppPaths.supportDirectory // read
side effect: Tokengotchi → Tokengochi directory migration

Untested; base directory not injectable, so load/save of Snapshot and Pet state hit real disk.

After — explicit migration, injectable root

App paths (injectable root)

migrateLegacyDirectoryIfNeeded()

real Application Support temp dir in tests
Problem.
The legacy-directory migration is real behaviour hidden as a side effect of reading a path; because the root isn't injectable, the migration, Snapshot load/save, and Pet state's forward-compat decoder are all untestable.
Solution.
Inject the base directory, name the migration explicitly, and point tests at a temp root — same seam pattern Snapshot store already proves out.

Wins

  • Migration gets a regression test
  • Pet state decoder defaults testable
  • No surprise side effect on read

Top recommendation

Collapse the vendor-JSON → Snapshot pipeline

It deepens the seam both producers depend on, deletes the duplicated compose dance in the Poller and Writer, shrinks Snapshot merge's 9-argument interface, and turns the entire ingestion path into ordinary Kit unit tests — and it makes candidate 2 smaller, because the Poller's only pure slice moves into Kit first.
