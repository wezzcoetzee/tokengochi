Concept & Build Plan

Tokengochi

A menu-bar virtual pet that is your Claude token usage. Feed it by working. Watch it grow. Don't overfeed it.

macOS · SwiftUI · 23 Jun 2026 · v0.1 draft

The Idea

A native macOS menu-bar app that reads your Anthropic subscription limits — the 5-hour session window, the weekly cap, and your live context window — and turns them into the vital signs of a Tamagotchi-style creature.

Every token you spend feeds the creature. It gets fatter through a session and slims back when the window resets. At usage milestones it pops out of the MacBook notch to react. Later, creatures get social — visiting, comparing, and competing with friends'.

Not a dashboard with a mascot bolted on — a pet whose entire existence is your usage.

Care mechanics — the healthy band

Core philosophy: using more is good; using less is the failure. There's no penalty for going big — the only way to harm the creature is to neglect it. And the only cure is to come back and use Claude.

Stats

  • Hunger ← session %. Usage feeds it; a starved window leaves a mess.
  • Happiness ← weekly %. More usage = happier, no ceiling penalty.
  • Weight ← accumulated usage. The visible (proud) fatness.
  • Health ← drained by uncleaned 💩; recovered only by using Claude.

Mess & cure

  • Wasted window — end a window under 20% used → 💩
  • Cleaning — no button; reach 25% in a later window to clean one 💩
  • Sick — uncleaned 💩 piles up, Health drops → Sick until you use Claude
  • Maxed (~95%+) — not a punishment: stuffed & napping until reset

Where the data comes from

Claude Code already receives real rate-limit percentages from Anthropic's API response headers and pipes them as JSON to its statusline command. Tokengochi installs its own tiny statusline writer that captures that JSON to a snapshot file; the app polls the file.

Claude Code session (active)
   │  pipes stdin JSON  { rate_limits.five_hour / seven_day, context_window }
   ▼
Tokengochi statusline writer  ──writes──▶  snapshot.json
   │
   ▼  poll (FSEvents + timer)
Tokengochi.app (SwiftUI)
   • MenuBarExtra  — session / weekly / context, "updated Nm ago"
   • Notch layer   — creature pops out & reacts at milestones
   • Pet engine    — maps %→size/mood, fires each milestone once

Honest constraint: there's no background API to poll subscription limits — numbers only refresh while a Claude Code session is active. But each limit carries a resets_at timestamp, so the app counts down accurately and snaps the creature back to "lean" when a window resets. A freshness indicator keeps it honest.

Real fields, verified locally: rate_limits.five_hour.used_percentage, rate_limits.seven_day.used_percentage, context_window.used_percentage (+ resets_at timestamps).
