2 · The 7 moods (exact rules from PetEngine)

🤒Sick
health < 40

Too many uncleaned messes. Beats every other mood. Cured only by using Claude.

😴Stuffed
session ≥ 95% or weekly ≥ 95%

Maxed out & napping until reset. This is a reward, not a penalty.

🍴Starving
session < 20%

Barely fed this window. Run a session to feed it.

😄Thriving
happiness ≥ 70

Strong weekly usage. The happy default for heavy users.

🙂Okay
happiness ≥ 35

Moderate weekly usage. Content but not glowing.

😔Lonely
happiness < 35

Light week so far. More usage cheers it up.

🥚No Data
no snapshot yet

Start a Claude Code session to wake it up.

Priority order is exactly: sick → stuffed → starving → thriving → okay → lonely. The legend lists them in this same order so the panel matches behavior.

3 · The vitals & their formulas

VitalFormulaWhat it means
Hunger100 − session%More session usage = more fed. Tokens are food.
Happinessmin(100, weekly% × 1.1)Monotonic — more weekly usage, happier. No over-use penalty.
Health100 − messes × 20Drops 20 per uncleaned mess. Below 40 → Sick.
Weight(weekly%×0.7 + session%×0.7) / 100Body size — "proud fatness." Grows as you spend.

4 · The 💩 mechanic (wasted windows)

  1. A window ends under 20% usedWhen the 5-hour session resets and your peak that window was below 20%, the pet leaves one 💩.
  2. Each 💩 costs 20 healthStack a few and the pet drops below 40 health → 🤒 Sick.
  3. Clean by using ClaudeReach 25% session usage in a later window and one 💩 is auto-cleaned — at most one per window. There is no "clean" button.

threshold 20%clean 25%−20 health / mess Constants come straight from PetEngine.wastedWindowThreshold, cleanThreshold, healthPerPoop.

6 · How I'd build it

  1. Add a legend data source in TokengochiKitA small HelpTopic list (icon, title, blurb) + a Mood.helpDescription and AnimationTier threshold list — so the UI reads the same constants the engine uses. Nothing hard-coded twice.
  2. Add the ? button to the menu headerIn MenuContentView, put a questionmark.circle button beside the title, bound to @State showingHelp.
  3. Build HelpViewA scrollable SwiftUI view (moods, vitals, 💩, animations) styled with the existing Phosphor palette and lcdReadout(). Toggles in place of the stats body.
  4. AccessibilityVoiceOver labels per row, button labelled, panel grouped — mirrors the existing screenAccessibilityLabel approach.
